# Триумф

Сайт-визитка команды для отборочного этапа «Волга.ТОП» 2026. Оформление взято из макета Алины и Тима в файле `TRIUMF.fig`. Для компьютера использована версия со светлым подвалом, для телефона — мобильная композиция из вложенного макета.

## Запуск

Распакуйте ZIP целиком. Для просмотра откройте `Открыть сайт.html` в браузере. Этот файл показывает версию сайта на момент упаковки.

Для разработки нужен Python 3.10 или новее. На Mac откройте `Запустить.command`, на Windows — `Запустить на Windows.bat`. Зависимости лежат в папке `wheels/` и устанавливаются из неё без интернета.

На Mac и Linux можно выполнить `python3 start_local.py` в терминале из папки с `manage.py`. На Windows команда для PowerShell — `py -3 start_local.py`.

Скрипт напечатает адрес и откроет его в браузере. Для остановки сервера нажмите Ctrl+C в терминале. Проверяйте изменения проекта через Django.

## Файлы проекта

| Ответственный | Что редактировать |
| --- | --- |
| Владос | `manage.py`, `triumf_site/` — запуск, настройки и адреса |
| Влад | `team/views.py`, `data/team.json` — данные участников и фильтр |
| Илья | `data/projects.json`, `team/tests.py` — проекты и проверки |
| Алина и Тим | `templates/`, `static/` — HTML, CSS, изображения и шрифт |

При запросе главной страницы Django читает два файла JSON. При запросе `/?skill=python` он выбирает подходящих участников. HTML собирается из шаблона, а CSS, изображения и Inter загружаются из проекта. База данных для этого сайта не нужна.

## Данные перед сдачей

- В `data/team.json` укажите согласованные имена или ФИО, роли, учебные группы, навыки и контакты. Поле `photo` принимает путь к файлу относительно папки `static`. Если оно пустое, сайт использует аватар из макета.
- Для общего контакта заполните `contact` объектом с полями `label` и `url`. Для репозитория заполните `repository` ссылкой GitVerse. Личный контакт карточки необязателен при наличии общего.
- Согласуйте названия, описания и статусы работ в `data/projects.json`. После проверки данных переключите `draft` в `false`.
- В итоговом README добавьте ФИО, группы, ссылки на личные профили в GitVerse, реальный вклад каждого, скриншоты и ссылку на видео. Стартовый README дополняется по приложению 1 отборочного задания.

## Проверка

```sh
.venv/bin/python manage.py check
.venv/bin/python manage.py test team
```

На Windows используйте путь к Python из команды запуска выше. В браузере проверьте меню на телефоне, фильтр по Python, сброс фильтра, раскрытие «Подробнее» и открытие согласованных ссылок. Публичное размещение требует отдельной конфигурации Django. Команда `runserver` служит для работы на своём компьютере.

## Использование искусственного интеллекта

Codex помог перенести предоставленный командой макет в HTML и CSS, перенести код Django из учебного черновика и проверить новую версию. При сдаче укажите фактические инструменты и модели, запросы, результаты, доработки и ответственных. Материалы значимых сессий в очищенном виде соберите в `ai-sessions.zip`. Укажите помощь ИИ, использованную при создании исходного макета, если она применялась.
