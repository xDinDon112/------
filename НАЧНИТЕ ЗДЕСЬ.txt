ТРИУМФ

1. Скачайте ZIP и распакуйте его целиком. Откройте папку «Триумф».
2. Чтобы просто посмотреть сайт, дважды щёлкните «Открыть сайт.html».
   Интернет и Python для просмотра не нужны. Файл открывается в браузере.
   Ссылки на внешние страницы работают при наличии интернета.
3. Чтобы работать над сайтом на Django, установите Python 3.10 или новее.
   Windows: откройте «Запустить на Windows.bat».
   Mac: откройте «Запустить.command» или выполните python3 start_local.py
   в Терминале из папки «Триумф».
   Linux: выполните python3 start_local.py из папки «Триумф».
   Зависимости уже в архиве. При первом запуске их установка займёт время.
4. Когда откроется браузер, оставьте окно с запуском открытым.
   Для остановки нажмите Ctrl+C в этом окне.

Для работы с кодом откройте README.md. После изменений проверяйте результат
через запущенный Django. Файл «Открыть сайт.html» показывает версию из архива.
